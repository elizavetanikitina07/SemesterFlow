# SemesterFlow

Тема курсового проекта — «Разработка веб-приложения для планирования учебного семестра».

## Технологический стек

- **Frontend** — React, Vite, React Router, Redux Toolkit, RTK Query и CSS.
- **Backend** — Node.js и Fastify.
- **База данных** — MySQL.
- **ORM** — Prisma. Изменения схемы базы данных оформляй миграциями Prisma.
- **Аутентификация** — JWT, передаваемый в заголовке `Authorization: Bearer <token>`. Для хеширования паролей используй bcrypt.

## Требования к приложению

- Реализовать регистрацию и авторизацию пользователей.
- Реализовать управление учебными дисциплинами и заданиями. Для обеих сущностей предусмотреть полный CRUD — создание, чтение, обновление и удаление.
- Добавить поиск и фильтрацию заданий.
- Предусмотреть отслеживание дедлайнов, оценок и статусов выполнения заданий.
- Разграничить доступ к пользовательским данным. На сервере проверять, что пользователь имеет право работать с запрашиваемой записью.
- Валидировать формы на клиенте и входные данные на сервере. Обрабатывать ошибки и показывать пользователю понятные сообщения.
- Предусмотреть не менее трёх маршрутов на клиентской стороне.

## Правила разработки

- Сначала разрабатывай backend, затем frontend.
- Выполняй задачи небольшими последовательными этапами.
- Не усложняй архитектуру без необходимости. Используй понятные названия переменных и функций.
- Соблюдай принципы безопасности. Не храни пароли и секретные ключи в репозитории. Передавай секреты через переменные окружения, а пароли пользователей храни в базе данных в виде хешей.
- После каждой задачи объясняй на русском языке, какие файлы изменены, зачем внесены изменения и как работает написанный код. Объясняй технические решения и предлагай способы проверки реализованного функционала.
- Не выполняй `git commit` и `git push` без разрешения пользователя.
- Не устанавливай зависимости без предварительного согласования с пользователем.
- Не добавляй функциональность за рамками текущей задачи.
